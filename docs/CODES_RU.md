# Codes: одиночное прохождение

v0.1.19: F1 / Cmd+, / Back + Start → Codes. Пять модификаторов по мотивам
Xbox 360 трейнеров (Aurora RETROBYTE и TeamXPG), все выключены по умолчанию и
применяются сразу, без перезапуска. Прогресс карьеры сохраняется обычным игровым
путём: результат, полученный с кодом, остаётся в карьере. Основной сейв нашим кодом
не редактируется.

| Code | Что делает | Проверено в игре |
| --- | --- | --- |
| Infinite Boost | Шкала boost игрока полная и на уровне 4 (720 в Race); выключение возвращает прежний уровень | Race / Road Rage: уровень 4, 720/720 при удержании A; ИИ не получает |
| Infinite Time | Срок события не уменьшается; штатные прибавки времени сохраняются. Выключение — отсчёт продолжается с замороженного значения | Road Rage: ~60 с держится 50+ с езды; выключение в меню посреди события → 99,99 → 91,7 без скачка, событие штатно завершилось, экран итогов |
| Quick Money | Каждое начисление Traffic Attack не меньше $30 000 | Traffic Attack: Traffic Check 3 000 → 30 000; HUD $2 220 000 при золотой цели $1 250 000 |
| Quick Takedowns | После первого настоящего Takedown игрока счётчик события = 99, дальше растёт штатно | Road Rage: HUD 100+, итоги **108 Takedowns, GOLD, AWESOME** |
| Easy Boost | Near Miss заполняет текущую шкалу; ниже пороги скорости/дистанции Near Miss и дрифта | Race: шкала 0/240 → 240/240 на первом Near Miss |

## Ограничения

- Online Play должен быть выключен **при запуске**. Если включён, выключить его и
  перезапустить игру; даже одиночный заезд в таком процессе не получит Code.
- Локальный Multiplayer, поочерёдный Crash, Burnout Clips и машины ИИ исключены.
  В Crash расход boost и Crashbreaker не меняется.
- Защита работает непосредственно в hook каждой функции игры; переключатель
  меню и переменные окружения (`BURNOUT_INFINITE_BOOST` и т. п.) её не обходят.
  Неизвестная сессия отвергается.
- Infinite Time: событие с окончанием по времени не закончится, пока код включён —
  то же предупреждение было у трейнера RETROBYTE («Must Disable Inf Time At the End
  of Each level»). Road Rage заканчивается и по разбитой машине.
- Quick Takedowns/Money меняют итог события и медаль в карьере. Подсказка «Gold at N»
  в HUD пересчитывается игрой только при следующем пороге.
- Произвольная запись в память, менеджер внешних кодов и Unlock All не предоставляются.

## Сопоставление с трейнером Aurora RETROBYTE

[Trainer(RETROBYTE).xex](https://github.com/StonedModder/Aurora-JTAG-RGH-Trainer-Pack-Repository/tree/main/Aurora/user/Trainers/454107DC)
(XYZEngine, Title ID 454107DC) дизассемблирован только для сравнения; его бинарные
патчи не переносились. Адреса трейнера относятся к **другой сборке** исполняемого
файла (вероятно, TU1): в нашем USA XEX по ним другие инструкции. Поэтому каждая
функция найдена заново по смыслу кода и проверена в игре.

| Трейнер (его сборка) | Наш USA XEX | Наша реализация |
| --- | --- | --- |
| Inf Time: `0x8236BF34` `add r9,r11,r9` → `addi` | срок события в объекте события, метод остатка `sub_8212DE50` | сдвиг дедлайна на прошедшее игровое время только для текущего одиночного события |
| Easy Money: `0x82324E00` `add r3,r3,r10` → `addi r3,r3,30000` | та же функция начисления `sub_82324D58`, сложение по `0x82324DC0` | сумма вызова поднимается до ≥ 30 000 (с учётом множителя), только игрок 0 |
| Max TakeDowns: запись 99 в `0x8276FC2C` каждый тик | статистика события, шаг 0xC8: `+0x70` — итог, `+0x9C` — счётчик цели/медали/HUD (`0x8276FB80` / `0x8276FBAC` для игрока 0) | после настоящего Takedown игрока (`sub_8212F168`, обработчики режима `sub_82134B80` / `sub_82136498`) оба поднимаются до 99 |
| Inf Boost: 500.0f в `0x82CE34F0` каждый тик | объект boost машины: уровень `+88`, ёмкость `+92`, запас `+96` | штатная ветка бесконечного boost и уровень 4 из таблиц игры |

Первая версия Quick Takedowns писала только `+0x70`: внутренний счётчик был 99, а
HUD показывал 1, итоги — «105 Takedowns, медаль NONE». Отладка записью-ловушкой на
странице памяти показала, что HUD (`sub_821A1830`) копирует `+0x9C`, а медаль
и цель события сравнивают его же с порогами (код по `0x8212C70C` и `0x82141E2C`). После исправления
итог и медаль совпали.

## Реализация и проверка

Только поддерживаемый USA XEX. Оригинальные функции вызываются всегда; модификация
делается до/после вызова и только при одиночной сессии, одном локальном игроке,
отсутствии сетевого режима и человеческой машине игрока 0. Временные изменения
(флаг бесконечного boost, пороги Near Miss) восстанавливаются сразу после
оригинальной функции, в том числе при раскрутке стека.

`codes_test` (ASan) выполняет настоящие hooks через PPC ABI на защищённых
страницах: онлайн, локальные режимы, Crash-контроллеры, ИИ, неизвестные сессии,
невалидные параметры шкалы, переключение настроек, Off таймера, восстановление
флага и порогов при исключении, оба счётчика Takedown. Полный набор CTest **77/77**.

Игровые прогоны — копии профилей, BURNOUT_MUTE=1, каждый код отдельно (остальные
выключены). Навигация по меню в тестах — через `BURNOUT_INPUT_LIVE`: по одному
нажатию с проверкой кадра после каждого, без расчёта задержек загрузки.

## Бонусные машины (исследование, не Codes)

### Особые машины: проверенный результат

На [странице GameFAQs](https://gamefaqs.gamespot.com/xbox360/928661-burnout-revenge/cheats)
есть записи разных платформ. Условия с сохранением Burnout 3 для Dominator Assassin
и Madden NFL 06 для автобуса помечены Xbox/PS2. Отдельно приведён способ с трейлером Madden.
Нельзя переносить условие с сейвом старой платформы в Xbox 360 автоматически.

**В нашей USA Xbox 360 версии сработал штатный путь:** World Tour → Y (Driver Details)
→ Special Features → Madden NFL 06 Trailer → A. На изолированном раннем профиле,
с Infinite Boost и Online Play выключенными, игра показала:
«Congratulations! You've unlocked the Madden Van!». Затем открыла NFL_E_N.xmv.
Сейв Madden не добавлялся; профиль и флаги не редактировались нашим кодом.
Отдельная кнопка Codes для этого не нужна.

![Штатное сообщение о разблокировке Madden Van](screenshots/codes-madden-unlock.png)

Проверено сообщение разблокировки. Выбор машины в Crash, заезд на ней и сохранение
бонуса после перезапуска пока не проверены. Для Dominator Assassin подтверждено
наличие имени в MainUS.bin, но условие открытия на 360 здесь ещё не проверено.
Наличие строки не считается доказательством доступной машины.

### DLC и Unlock All Cars

[Официальное объявление Xbox от 14.04.2006](https://news.xbox.com/en-us/2006/04/14/burnout-revenge-car-unlocks/)
называет шесть бесплатных Marketplace-разблокировок: Alienware, Dolby, Monster,
Plantronics, SpikeTV и Yellowcard. Это сведения о выпуске 2006 года, не обещание
доступности загрузки сейчас.

В шести установленных пакетах пользователя после штатной распаковки найден только
15-байтный Content.txt, без моделей и текстур. Следовательно, эти пакеты служат
маркерами для ресурсов игры. Это делает офлайн-разблокировку перспективной; само
по себе наличие маркеров не доказывает выбор всех шести машин в одиночной карьере.
Пользователь подтвердил 21.10, что с этими DLC машины становятся доступны в порте.
Остаётся отдельная проверка будущего Code без add-ons: выбор каждой машины и её загрузка.

Исследованы отдельные штатные функции членства машины в каталоге, её разблокировки
и подсчёта открытых машин. Простая замена проверки на true небезопасна: неизвестный
ID уже возвращает true в одной из функций. Надпись Unlock All найдена и в отладочных
ресурсах, но рабочая цепочка её применения не подтверждена. Ничего из этого пока
не включено в Code.

Предпочтительный вариант — временно открывать для одиночного выбора только проверенные
машины, чьи ресурсы есть в установленной игре. Выключение должно возвращать исходные
ограничения. Не выдавать 100% карьеры, медали или достижения за открытие гаража.
Контроль нужен и при выборе машины, и при входе в режим: бонус, выбранный офлайн,
не должен переноситься в Multiplayer. Для проверки использовать ранний профиль и
отдельный каталог без add-ons; доступность машины и её реальная загрузка — разные проверки.

## Что ещё не проверено

- Реальный split-screen и две LAN-копии ранее отвергали Infinite Boost даже при
  принудительном включении; для остальных кодов эти отказы проверены ABI-тестом.
  Между двумя физическими Mac не проверялось.
- Burnout Clips с принудительным Code отдельно в игре не проверены (только ABI-тест).
- Easy Boost против выключенного кода не сравнивался в одном и том же заезде;
  разница показана переходом 0 → 240 на первом Near Miss.
