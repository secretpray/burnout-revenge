2. [x] **Четыре ошибки рендера из отчёта по Xerenge** (проверено 18.10, прогоны 198–201): все четыре —

   - Переполнение вершин: у нас нет буфера вершин на 524288 — вершины читаются прямо из памяти
     гостя, кольцо per-draw данных при заполнении отправляет работу, а не отбрасывает draw.

     масштабируется; g_HalfPixelOffset считает сам гостевой D3D. Сдвига bloom нет.
   - Scissor: берём `PA_SC_WINDOW_SCISSOR` (то, что видит GPU), а не прямоугольник D3D +0x3220.
     `BURNOUT_LOG_CLEARS=1` пишет и draw с пустым scissor — за гонку, Crash-камеры и Replay: 0.
     Белый кадр в начале Replay — штатный переход игры через белое.
