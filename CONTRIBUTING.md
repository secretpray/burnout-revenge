# Contributing

Report issues with the app version, Mac model, macOS version, controller connection
(USB/Bluetooth), reproduction steps and expected/actual result. The in-game bug
report is saved locally for you to inspect before sharing; nothing uploads itself.
Do not attach ISOs, XEX files, generated game code, extracted data or private saves.

Keep changes scoped to Burnout Revenge USA. Preserve original authorship and
license headers. Run the applicable tests and document every runtime launch,
including failed or inconclusive runs. Rendering comparisons require the same
scene and output size; do not label a menu as an active-race benchmark.

Live MetalFX frame generation requires validated motion/depth/HUD inputs, bounded
GPU ownership, event synchronization, camera-cut resets and frame pacing before
it can be offered to players. A successful offline interpolation is not a
successful in-game implementation.
