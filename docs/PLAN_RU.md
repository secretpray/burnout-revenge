условий или ручной проверки. Обновлять после каждого этапа. История запусков и подробности
сделанного — в git (коммиты) и [PROGRESS](PROGRESS.md); для игроков — README и
[ONLINE](ONLINE.md).

## Очередь (по порядку)

### 1. Codes для одиночного прохождения — готово (v0.1.19)
Пять кодов по мотивам трейнеров Aurora RETROBYTE / TeamXPG: Infinite Boost (уровень 4),
Infinite Time, Quick Money, Quick Takedowns, Easy Boost. Каждый проверен в игре отдельно
(остальные выключены) и ABI-тестом с ASan; CTest 77/77. Подробности, сопоставление
адресов трейнера с нашим XEX и пределы проверок — [CODES_RU](CODES_RU.md).

Главная находка: у события два счётчика Takedown. `+0x70` статистики — итог на экране
результатов, `+0x9C` — цель, медаль и HUD. Первая версия поднимала только первый
(итоги «105, медаль NONE»); теперь оба, итоги «108, GOLD, AWESOME».

Для игровых проверок добавлен `BURNOUT_INPUT_LIVE`: тест дописывает команды в файл
(«0:A», SHOT, CLEAR, «KEY F1») и смотрит кадр перед следующим нажатием. Это заменило
скрипты по времени: задержки загрузки меню нестабильны (подсказка на главном меню,
долгая анимация выбора ранга), из-за чего прогоны уходили не в то событие.

Не сделано и не входит в релиз: Unlock All / машины DLC без пакетов, Maximum Boost
Level отдельно от Infinite Boost. Madden Van открывается штатно (Driver Details →
Special Features → Madden NFL 06 Trailer); гараж/заезд на нём не проверены.
Правила остаются: только одиночный офлайн; защита в hook игры; без произвольной
записи в память и чужих кодов.

### 2. Оригинальные достижения Xbox 360
Уточнение пользователя 21.10: отдельный высокий приоритет после Codes.
Игра сама сообщает о разблокировке по исходным условиям Xbox 360; сохранять
ID и время локально, показывать уведомления и постоянный список исходных достижений.
Использовать названия, описания и изображения из ресурсов копии игры пользователя;
не придумывать заменяющий набор заданий. Дедупликация, перезапуск и раздельные профили.
Честно отмечать отсутствие синхронизации с Xbox Live/Steam/RetroAchievements;
онлайн-достижения проверять только по настоящим сообщениям игры, без автозачёта.
Учитывать локализацию встроенного экрана достижений. В XDBF USA XEX уже найдены
36 оригинальных достижений (ID 58–93), суммарно 1000 Gamerscore; таблицы строк
EN/JA/DE/FR/ES/IT и изображения. Это чтение метаданных, не проверка разблокировки.

### 3. Откат 10 / 20 / 30 секунд
Пользователь уточнил: нужен именно rewind, перезапуск заезда с начала не нужен.
Сначала эксперимент восстановления мира текущей одиночной гонки, затем RAM-кольцо,
замеры и горячая клавиша/пункт меню. Файловые слепки/менеджер слотов не приоритетны.
Ограничения и критерии эксперимента — NEW_FEATURES_RESEARCH_RU.md.

### 4. Профили и камера

re:Blue. Новые сетевые рейтинги не добавлять.

### 7. Локализация всех новых меню порта
По запросу пользователя 21.10: английский, японский, немецкий, французский,
испанский и итальянский; ориентир — Custom Localization в
[Unleashed Recompiled](https://github.com/hedge-dev/UnleashedRecomp#custom-localization).
Общий каталог строк для настроек, установщика, диалогов, Codes, rewind и будущих
экранов; переводить также подсказки, ошибки и действия. Проверить шрифты с японскими
глифами, длинные строки, навигацию падом и согласованность языка с игрой.
Сейчас XGetLanguage жёстко возвращает English; наличие шести языков у Unleashed
не доказывает их наличие в нашем USA-издании Revenge. Сначала проверить ресурсы
Revenge и безопасный fallback для отсутствующих игровых переводов. Пользователь
предложил предоставить EU-издание для поиска остальных ресурсов; при переходе
к этому этапу использовать его для проверки, не подменять USA XEX другим регионом.
Японский логотип титульного экрана — только если подтверждён оригинальный ресурс
Revenge и его загрузка из копии игры пользователя; не переносить логотип Sonic.
Закладывать локализуемые строки при добавлении новых меню уже на этапах 1–6.

21.10 пользователь предоставил два ISO на `/Volumes/1Tb NVME/XBOX360`:
- `Burnout Revenge (Europe) (En,Es,Nl,Sv,Fi).iso`: MainUK/Sp/Du/Sw/Fi.
- `Burnout Revenge (Europe) (Fr,De,It).iso`: MainUS/UK/Sp/Fr/Ge/It/Ja/Ko/Du/Sw/Fi,
  соответствующие Cred*.bin и шрифты Japan.bin / Korea.bin.

Каталоги ISO прочитаны напрямую, без изменения образов или установленной игры.
У всех Main*.bin по 4270 записей; японский MainJa содержит японские/кандзи-символы
в 3459 записях. Это подтверждает ресурсы шести запрошенных языков; правильность
подстановки, выбор языка, шрифты в игре и японский логотип ещё не проверены.
XEX европейских образов отличаются SHA от USA: не заменять исполняемый файл
под существующим generated code. На этапе локализации исследовать загрузчик строк
и выбор языка; перевод меню порта всё равно нужен отдельно. Сырые игровые ресурсы
не добавлять в репозиторий. [Подробный отчёт по обоим EU ISO](LOCALIZATION_RESEARCH_RU.md).
UK/Sp/Du/Sw/Fi: все 4270 ключей и строк совпадают между образами; подтверждены
реальные переводы, а не только имена файлов. Частный инвентарь — speedbreaker/build/localization-audit.

  жалобах на мыло.
- **Смена частоты внешнего экрана в fullscreen** (144/165 → 120 Гц) — нужен такой монитор
  для проверки; без проверки не делать.
- **Обновления SpeedBreaker** — каждый релиз upstream разбирать на пользу для Mac.

## Справка: онлайн для разработки

- **Фазы 0–7 сделаны** (19–20.10): консоль «в Live» (`user/online.*`, XNADDR, XUID на
  геймертег), хуки входа (`game/online_hooks.cpp`, `game/online_log.cpp` — адреса Xerenge,
  сверены с нашей USA-сборкой), свой сервер (`runtime/thirdparty/ealobby` — Xerenge `cfe047e`
  без изменений + наши правки, README там же; `burnout-lobby`, тест `ealobby_test`), гонка
  на двоих, 3–4 игрока и LAN (лобби в игре, `BURNOUT_LOBBY_SERVER=lan`), Burnout Clips через
  Locker, Settings > Online.
- **Сеть** (`kernel/burnout_imports.cpp`): порты ниже 1024 → +30000 (как `MapWirePort` у
  Xerenge); общий UDP-порт 8192 — сокет на игрока (`SharePort`/`ExpectPeer`/`Route`, правило
  Xerenge); перекрытый приём через свой поток; `WSAGetOverlappedResult` ставит код через
  `SocketFailure` (иначе поток приёма DirtySock `0x824163B8` бросает сокет); пауза повторов
  входа 5→60 с (`online::LobbyConnectAllowed`).
- **Протокол лобби**: Aries — заголовок 12 байт (команда, код, длина BE) + `KEY=VALUE`, NUL;
  `@dir` на 31860, лобби 31861, Locker HTTP 31862 (`locker.jsp?cmd=dir|get|put|del&lkey=…`),
  LAN-анонсы UDP 31859 и связь лобби `xhlo/xjoi/xfwd/xlea`. ID игрока — FNV-1a геймертега.
- **Протокол между игроками**: порт 1000 — байт 2: 1 запрос / 2 подтверждение / 0 без; байт 3 —
  тип (`0x15` приглашение хоста, `0x05` соединение, `0x08` список игроков, `0x0D/0x0E` пинг);
  далее номер и ID «от → кому» (младшие 32 бита XUID без старшего бита). Порт 8192 — CommUDP:
  новичок ждёт каждого (`connect ":8192:8192#$свой-$чужой"`, состояние 3), сидящие зовут его
  (`listen "<адрес>:8192:8192#…"`, состояние 2); привет `00 00 00 01` + хеш ключа, ответ
  `00 00 00 02`; связь 4 → обе стороны шлют `0x05` на порт 1000. Журнал состояний — в
  `game/online_log.cpp` (`BURNOUT_LOG_NET=1`).
- **Автоматические прогоны — без звука**: `BURNOUT_MUTE=1` (пожелание пользователя
  21.10). Настройки звука пользователя не менять.
- **Боты** (`…/speedbreaker/build/online-validation/bots.py`): 2–4 копии на 127.0.0.2–5, сценарий
  пада по событиям игры (`@menu`, `@online`, `@session`, `@race`, `@raceend`), `BOTS_MODE` 1–4
  (Road Rage, Crash Party, Crash Tour, Crash Battle), сервер `127.0.0.1` или `lan`.
